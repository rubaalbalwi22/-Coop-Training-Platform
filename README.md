# Coop Training Platform

A mobile application designed to help university students find cooperative training opportunities and manage their training experience.

## Features

- Search for cooperative training opportunities
- Submit and manage CVs
- Filter opportunities based on major
- Receive feedback and ratings after training
- User-friendly mobile interface

## Technologies

- Flutter
- Dart
- Firebase
- Android Studio

## Project Purpose

The project aims to make the cooperative training process easier for university students by providing a centralized platform to discover suitable training opportunities.
